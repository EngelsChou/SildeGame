# GOGO RPG

繁體中文、明亮奇幻的 2D Web ARPG。以短場次怪群戰鬥、隨機裝備及永久角色養成為核心，依 Vertical Slice 逐步完成可持續營運的完整遊戲。

目前版本 **0.1.0：本機可玩開發版本**。已建立戰鬥到養成的基礎循環；這不是正式上線版，雲端帳號、最終素材及產品驗收仍在後續里程碑。

## 啟動

已在 Windows／Node 24.16.0 驗證。首次安裝：

```powershell
npm.cmd ci --cache .npm-cache
npm.cmd run dev -- --port 5173
```

開啟 <http://127.0.0.1:5173/>。開發伺服器只監聽本機。

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run preview -- --port 4173
npm.cmd run format:check
```

`build` 先執行 TypeScript 檢查，再輸出 `dist/`。目前 Phaser 與遊戲共用主要 JS bundle，Vite 會提示超過 500 KB；這是容量提示，尚未完成網路限速載入驗收。

## 怎麼玩

1. 營地選擇普通難度，按「出發冒險」。
2. WASD／方向鍵移動；靠近敵人自動揮劍，主鍵盤 1／2 或右側數字區 1／2 施放技能。Esc 暫停。
3. 初始學會旋風斬。第一個階段守衛的衝刺斬書提供第二招；拾取後回營地學習，再手動配置技能格。
4. 主階段 120 秒，每 20 秒生成守衛。120 秒清除普通怪與敵方投射物，生成最終守衛；擊敗所有存活守衛才通關。
5. 靠近拾取裝備與書籍。勝利補收地面所有裝備與書籍；死亡或放棄保留經驗和已拾取收益。
6. 在背包穿戴、鎖定或出售裝備，商店購買裝備／技能書，工坊強化至 +5。通關解鎖下一難度並刷新商店。

技能永久習得，**沒有技能等級**；普通、稀有、大師、傳說、神話是技能固定品階。同時配置兩招，第一版只開放劍系。

## 戰鬥回饋更新

普攻與重劈使用掃動刀光、獨立劍身與角色出刀動作；旋風類招式加入旋轉劍影。命中會產生火花、短暫閃色與後仰，玩家受傷時有輕微畫面震動，碰撞障礙或怪物時有塵土及輕音效。後仰是視覺位移，碰撞位置及傷害規則維持原設定；Boss 的視覺後仰較小。特效隨戰鬥暫停，顯示數量有上限。

## 存檔邊界

- 目前只使用 `LocalPreviewRepository`，資料保存在 `gogo-rpg.development.profile.v1`，鍵位與音效設定另存。
- 存檔依瀏覽器及 origin 隔離；`localhost`、`127.0.0.1` 或不同 port 不共用資料。請固定同一網址試玩。
- 經驗及拾取收益即時保存，場次本身不續接。關閉／重新載入後回營地，地面未拾取物失去。
- 本機預覽以單分頁使用；尚無跨分頁角色鎖。清除瀏覽器資料會清除本機進度，可先從設定匯出 JSON。
- **尚未連接 Supabase 或 Google 登入**。本機資料不是伺服器可信資料，也不會自動成為正式雲端角色。
